プレイの型 — どう進めたか

Act1 序盤6マス そのステージで得た金(G)41負79.96 → 勝111.1
目盛りは 左＝自分の負けラン平均 → 右＝勝ちラン平均。基準は勝ち111本 / 負け101本（途中放棄は除外）。踏破したステージ同士でしか比べていない — 死んだステージを混ぜると「Act3を抜けた時の残HPは負けなら0%」のような、負けたことを測り直しただけの数字になる。差が確認できた指標(|t|≥2)だけを並べている。デッキの役割(@タグ)の枚数も指標にしてあるが、役割の枚数と勝敗の相関はほとんど無い（9役割×4時点で相関係数の最大が0.18、カードの質で測っても勝ち41.1%/負け41.6%）ので、ここに出るのは総当たりの多重比較を補正しても残ったものだけ。ほかに条件を外した原則が1件あるが、履歴で勝率差が確認できていないので出していない。 原則は tool/プレイ原則.txt に追記できる（py tool\play_style.py --check で検証）。いずれも相関であって因果ではない。
